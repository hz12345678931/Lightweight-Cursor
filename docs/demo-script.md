# 五分钟演示脚本

正式录像前配置真实模型，重新复制 `demo_project` 到演示文件夹。不要使用 `local-protocol-fixture-NOT-AI` 录制作业正式视频。

| 时间 | 操作 | 应展示的证据 |
| --- | --- | --- |
| 0:00–0:30 | 从安装入口双击启动，打开示例 | 原生窗口、标题栏、三栏、已安装版本 |
| 0:30–1:10 | 打开 stats.py，点击项目地图；对话解释 mean | Python 符号、上下文和流式回答 |
| 1:10–1:40 | 新建 Python 函数，开启补全，Tab 接受 | 行内补全确实插入代码，保存 |
| 1:40–3:10 | Agent 修复 mean 空输入；先运行测试，再审阅差异 | 失败测试、精确修改、确认写入、测试通过 |
| 3:10–3:40 | 让 Agent 调用 python-guide 的 python_tip | 外部工具来源、确认、真实 JSON-RPC 返回 |
| 3:40–4:15 | 要求读取不存在文件再重新找正确路径；停止一个等待任务 | 红色失败、后续恢复、停止真正结束进程 |
| 4:15–4:40 | 展示独立后端 SSE 或导出 trace.md | 流式事件、工具调用与结果可追溯 |
| 4:40–5:00 | 说明限制与后续方向 | 仅 Python、非 OS 沙箱、模型依赖、无复杂插件系统 |

现场突发任务应在新的小型项目执行，说明你如何读代码、审阅差异和验证结果。视频保存为仓库要求的 `demo.mp4`，录像中隐藏真实 API Key、账户信息和无关个人路径。`trace.md` 使用实际模型运行后从界面重新导出，保留一次失败及恢复过程。
